# TODO tasks

This directory contains documented work that is **available and unclaimed**.

Before creating a new task, inspect `implementing/`, open pull requests, this
directory, `completed/`, and the current repository state for equivalent work.

Create tasks with `python scripts/task.py new ...` when practical. A TODO must have
`status: todo`, no claimant, no branch, and no PR. Do not implement from this
directory; claim the task into `implementing/` first.

See `docs/AGENT-TASK-LIFECYCLE.md`.
