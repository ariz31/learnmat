# Improve an existing asset

Inspect current source and review evidence. Record a reproducible defect or a
specific educational improvement using templates/IMPROVEMENT.md. For numerical
changes, establish the expected result independently before editing.

Preserve original examples. Create a derivative in assets/ when extracting or
improving an intake source, with derivedFrom pointing to its stable ID. For an
existing curated asset, work in place on an authorized branch and update version,
usage, metadata, and review evidence as appropriate.

Treat educational value as part of the defect surface. Ask whether the asset teaches
a meaningful concept or procedure, or merely produces an attractive final visual.
When a real procedure exists, preserve the reasoning chain as completely as
practical: objective/data, conventions, governing relation, meaningful intermediate
results, visual consequence, check, and conclusion. Verify important computations
independently before presenting them as instructional steps.

Keep the default learner view concise. Prefer short labels, active-step information,
tooltips, and expandable derivations rather than permanent paragraphs. For
interactive or animated assets, provide a focus/maximize presentation mode that
hides lesson steps and nonessential chrome while keeping an obvious exit and
essential pause/play/reset controls.

Animation should explain sequence, causality, direction, scale, or state change.
Improve abrupt, misleading, cluttered, or decorative motion.

For spatial subjects, treat a flat primary visual as an improvement target. Prefer
real 3D geometry, coherent depth, camera framing, contextual scene elements, and
spatial animation comparable in ambition to the surveying examples. Preserve exact
2D equations, plots, labels, dimensions, and sections as overlays. If the primary
visual should remain 2D, record the concrete educational reason instead of silently
choosing the easier renderer.

Check engineering and interaction consequences, including reset mid-animation,
repeated actions, resize, focus/maximize entry and exit, mobile/touch behavior,
reduced motion, and error states. Capture real visual evidence. Submit the change
with observed results and remaining limits; do not promote or merge based solely
on an unsupported quality score.

Suggested request: “Audit this asset for engineering correctness and educational
quality. Fix missing or inaccurate procedural steps, reduce unnecessary text,
improve purposeful animation, and add a focused presentation mode without changing
the archived original source evidence.”
