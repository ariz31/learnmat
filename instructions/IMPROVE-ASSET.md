# Improve an existing asset

Inspect current source and review evidence. Record a reproducible defect or a
specific educational improvement using templates/IMPROVEMENT.md. For numerical
changes, establish the expected result independently before editing.

Preserve original examples. Create a derivative in assets/ when extracting or
improving an intake source, with derivedFrom pointing to its stable ID. For an
existing curated asset, work in place on an authorized branch and update version,
usage, metadata, and review evidence as appropriate.

Check engineering and interaction consequences, including reset mid-animation,
repeated actions, resize, and error states. Capture real visual evidence. Submit
the change with observed results and remaining limits; do not promote or merge
based solely on an unsupported quality score.

Suggested request: “Audit the profile-leveling asset, reproduce incorrect
behaviors, fix them in a derived component, and document checks without changing
the archived original.”
