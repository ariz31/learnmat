# Reuse in a single-HTML lesson

Read docs/REUSE.md and the selected asset's README, metadata, and model source.
Identify whether the user needs offline, CDN-dependent, or hosted delivery.
Check rights and review state. A candidate can be a development reference, but
must not be presented as an approved public asset.

Keep the engineering model separate from lesson copy and UI. Scope styles and DOM
selectors, preserve units and conventions, and pin dependencies. Include required
credits and a clear network requirement. Avoid unrelated global event listeners.
Validate the relevant numerical example, controls, narrow-screen layout, and
reduced-motion behavior. Describe untested limits in the result.

Suggested request: “Use an approved pace-factor component to create one HTML
lesson. State whether it needs a network, preserve the counting convention, and
include the asset version and attribution.”
