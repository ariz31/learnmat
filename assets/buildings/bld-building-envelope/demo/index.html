Building envelope

Orbit a dimensional shell. Openings are true facade voids; the cutaway exposes floor plates.

H = floors × floorHeight
bay width = width ÷ bays
Teaching sequence
  1. Set overall width, depth, floors, and floor height.
  2. Divide the facade into repeated bays.
  3. Inspect sill, opening, and head geometry as actual voids.
  4. Increase cutaway to expose floor plates spatially.
  5. Interpret geometry only; no code or structural adequacy is implied.
