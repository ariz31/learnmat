Staircase geometry

Change rise, risers, going, and width while the spatial flight rebuilds from the same arithmetic.

riser = totalRise ÷ risers
goings = risers − 1
run = goings × going
Teaching sequence
  1. Set the floor-to-floor total rise.
  2. Select a riser count and compute one riser height.
  3. Recognize that a flight ending at the upper floor has one fewer going than risers.
  4. Inspect run, width, and geometric pitch in 3D.
  5. Do not treat these controls as a code-compliance checker.
