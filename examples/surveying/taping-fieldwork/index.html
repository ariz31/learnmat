Taping fieldwork

Measure the horizontal line, not the ground surface.

Direct taping is a geometry-and-control exercise: establish the line, align the tape, apply consistent pull, transfer marks accurately, tally full lengths, and repeat the measurement independently.

Level ground

Use full tape lengths where practical, then measure the final remainder.

Uneven ground

Break the line into shorter horizontal segments and transfer each endpoint vertically with a plumb bob.

Verification

Repeat forward/backward or uphill/downhill, then compare by discrepancy and relative precision.

Field kit

Steel tape, range poles, marking pins/chalk, plumb bobs, and a tension handle or spring scale. A hand level is useful for breaking tape.

Level ground / seven-step workflow

Align → pull → steady → mark → advance.

1 · Establish

Mark A and B, set range poles, and confirm a clear sight line.

2 · Start

Rear tapeman fixes the 30 m mark at A; head tapeman carries the 0 m end forward.

3 · Align

Rear sights toward B and directs the head left or right onto line.

4 · Tension & mark

Apply consistent pull, hold the tape steady, then place the marking pin.

5–6 · Advance

Leapfrog the crew, tally full lengths, then measure the final partial segment.

7 · Reverse

Use the Return B→A control to animate the crew back through P2 and P1 before closing at A.

Breaking tape / uneven ground

Replace one sloping measurement with horizontal steps.

Each accepted segment must be horizontal. Hold the tape level, use a plumb bob to transfer the tape mark vertically to the ground, set the next pin, then repeat.

Horizontal segment

Do not hold the tape parallel to the slope. The tape itself represents a horizontal distance.

Vertical transfer

A plumb bob projects the head tape mark vertically to the ground point.

Leapfrog + return

The new pin becomes the next rear control point. The downhill D→C return is animated with the same horizontal-segment and vertical-plumb geometry.

Error control

Most taping error is visible in the geometry.

Misalignment

A lateral offset makes the measured tape path longer than the intended line.

Sag & pull

An unsupported curved tape and inconsistent tension change the effective measured length.

Nonhorizontal break

A tilted segment on uneven ground is a slope distance, not the required horizontal distance.

Plumb transfer

A swinging or off-center bob shifts the point used for the next segment.

Tally

Missing a complete tape length creates a gross error even if every segment is individually precise.

Commands

Use short commands such as left, right, hold, pull, and mark.

Computation

Agreement is reported as relative precision.

Mean = (L₁ + L₂) / 2Example AB: (85.42 + 85.46) / 2 = 85.44 m.
d = |L₁ − L₂|Example AB discrepancy = 0.04 m.
N = Mean / d85.44 / 0.04 = 2136, so relative precision ≈ 1:2136.
