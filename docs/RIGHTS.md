# Rights, attribution, and provenance

The goal is public, freely usable learning assets with clear terms. Public source
visibility does not establish permission to redistribute every embedded image,
font, model, dataset, or dependency.

The repository has an MIT [LICENSE](../LICENSE) for repository work. Preserve its
notice in distributions. This does not automatically establish ownership or clear
third-party models, textures, fonts, or datasets. Record exceptions and dependency
licenses per asset; do not relicense imported work through a metadata edit.

Each asset records a rights status, license expression when known, a license text
path, attribution, and source provenance. Supplied examples currently use
`needs-confirmation` and a null license expression. They are not cleared for the
public reuse catalog. An asset must not be marked approved while rights remain
unresolved. Add dependency license texts/notices to redistributed bundles.

For user-supplied sources, record the original filename and a content hash; do not
invent an upstream author or repository URL. The extraction hashes in
catalog/provenance.json preserve the supplied HTML source bytes, including line
endings. Maintain source attribution when deriving a reusable component.

For contributions, request the source location, authorship/permission declaration,
license text, required credits, and any restrictions affecting commercial use,
modification, or redistribution. Keep unresolved materials as candidates. If a
published asset later has a rights issue, remove affected distribution as needed,
document the reason, and preserve a non-infringing replacement notice.
